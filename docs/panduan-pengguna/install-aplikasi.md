# Instal Aplikasi

Situs resmi Flagshiiip menyediakan tautan unduhan aplikasi **Flagshiiip** di [Google Play](https://play.google.com/store/apps/details?id=com.flagshiiip).

## Memasang aplikasi

1. Buka tautan Google Play di atas pada perangkat Android.
2. Ketuk **Instal**, lalu tunggu hingga pemasangan selesai.
3. Buka aplikasi dan ikuti alur pendaftaran atau masuk yang ditampilkan.

Setelah masuk, lanjutkan ke [Scan QR](./scan-qr.md).
