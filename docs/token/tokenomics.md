# Aturan Main Token

Setiap token punya aturan main: **berapa jumlah totalnya**, **dibagikan ke siapa saja**, dan **untuk apa dipakai**. Kumpulan aturan ini sering disebut **tokenomics**.

## Struktur & Spesifikasi Token FTN

Sistem ekonomi token dirancang secara transparan di platform [flagshiiip.io](https://flagshiiip.io):

| Parameter | Keterangan |
| :--- | :--- |
| **Nama Token** | Flagshiiip Tokenium |
| **Simbol (Ticker)** | **FTN** |
| **Jaringan Blockchain** | Polygon (Ethereum Layer-2) |
| **Standar Kontrak** | ERC-20 (Token Loyalitas) & ERC-721/1155 (Sertifikat Digital) |
| **Audit Keamanan** | Terverifikasi oleh **CertiK** & Berbasis Standar **OpenZeppelin** |

## 4 Pilar Distribusi Token FTN

1. **Hadiah Konsumen (*Consumer Scan Rewards*)**
   Porsi terbesar dialokasikan untuk memberi penghargaan kepada pembeli yang memverifikasi produk orisinal melalui aplikasi.
2. **Insentif Kemitraan Brand (*Brand Ecosystem*)**
   Mendukung brand manufaktur dalam menyelenggarakan program promosi loyalitas dan penukaran voucer eksklusif.
3. **Pengembangan Platform & Infrastruktur**
   Membiayai keberlanjutan infrastruktur server, pembaruan aplikasi seluler, dan inovasi keamanan kode QR pintar.
4. **Stabilitas & Likuiditas Ekosistem**
   Menjaga ekosistem tetap sehat, transparan, dan dapat digunakan secara berkesinambungan.

:::tip[Transparansi Blockchain]
Seluruh aturan distribusi dan pencetakan token dikunci dalam kontrak pintar (*smart contract*) yang tidak dapat diubah sepihak, memastikan integritas dan kepercayaan bagi seluruh pengguna.
:::
