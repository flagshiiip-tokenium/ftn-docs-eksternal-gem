# Service Packages

Flagshiiip provides two service packages for brands.

## Starter

For brands looking to begin protecting their products from counterfeiting.

- **Price**: IDR 500 per sticker
- **Minimum order**: 10,000 stickers

Features:

- Unique QR code on each sticker
- Blockchain-based authenticity verification
- Scanning through the Flagshiiip consumer app
- Monitoring dashboard (scans, locations, activity)
- Authentic or verified digital product certificate
- Anti-duplication (each QR code can only be claimed once)

## Custom

For brands requiring a more flexible and tailored enterprise system. Pricing is customized through direct consultation.

Includes all Starter features, plus:

- Custom QR code and sticker design
- Brand identity integration (logo and branded verification landing page)
- Token and loyalty reward mechanisms
- Custom smart contract deployment
